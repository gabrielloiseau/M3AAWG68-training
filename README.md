## Dataset

The workshop data is included in `data/`:

| File | Emails |
| --- | ---: |
| `train.jsonl` | 200 |
| `dev.jsonl` | 100 |
| `test.jsonl` | 150 |

Open the notebook with the Colab badge above and run the cells in order. The data preparation cell automatically downloads any missing dataset files from this repository into the Colab runtime's `data/` folder. No manual upload is needed unless the download fails. You will need your own Mistral API key for the classification steps.

For local Jupyter, clone the repository and open the notebook from the repository directory so the `data/` folder is beside it.
